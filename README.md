# Gouda Guidance Generator

A web widget for winning witty wisdom. Click the control to collect cheesy counsel.

## How to use

1. Open `index.html` in your web browser.
2. Click the "Get Good Gouda Guidance" button.
3. Read the ridiculous response.
4. Repeat.

## How it works

The application fetches advice from an API and displays it randomly. The user interface is built with HTML, CSS, and JavaScript.
