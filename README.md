# Cheesy Advice Generator

This is a simple web application that displays cheesy advice. Click the button to get a piece of "advice".

## How to use

1. Open `index.html` in your web browser.
2. Click the "Get Some Gouda Advice" button.
3. Read the cheesy advice.
4. Repeat.

## How it works

The application fetches advice from the Advice Slip API and applies cheese puns to it. The user interface is built with HTML, CSS, and JavaScript.
